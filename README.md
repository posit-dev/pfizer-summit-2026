# Pfizer Summit 2026

Content for the Pfizer Summit 2026 workshop. This repository combines the
[Posit Team User Training Workshop](https://github.com/posit-dev/user-training-workshop)
lessons with two Posit Assistant demo scenarios.

## Lessons

1. **`01-positron101/`** — Getting started in Positron with R and Python weather analysis.
2. **`02-static-report/`** — Building a static, reproducible report with Quarto.
3. **`03-interactive-content/`** — Creating and deploying interactive content with a Shiny app.
4. **`04-bad-plot/`** — Using Posit Assistant to fix a visualization bug (gas prices).
5. **`05-eda/`** — Exploratory data analysis with Posit Assistant across a handful of datasets.
